# Rock Paper Scissors

A classic Rock Paper Scissors game played in the browser, built as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum.


## Description
This project implements a web-based Rock Paper Scissors game where a human player competes against a computer opponent. The game tracks scores, evaluates round winners based on game logic, and announces the ultimate champion after 5 points.

## Built With
* HTML5
* JavaScript (ES6)
